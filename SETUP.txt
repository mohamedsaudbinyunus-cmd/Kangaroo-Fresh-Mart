KANGAROO FRESH MART - TWO FILES
===============================
  index.html   the shop your customers use
  admin.html   your admin page (add / delete products, prices, stock, photos, offers, coupons, orders)
  images/      (optional) real product photos
Nothing else is needed. Each file contains everything inside it.

THE ONE SETTING BLOCK
  Open index.html AND admin.html in a text editor and find the block that starts with
  "SHOP CONNECTION SETTINGS" (near the top of the first <script>). It must be the same in both files:
      firebaseUrl:"..."   (same in both files)
      apiKey:"..."        (needed in admin.html; may be left empty in index.html)
      localPin:"1234"     (admin.html, Local mode only)
  Leave firebaseUrl empty to try everything on your own computer (Local mode). For the real, published shop use Cloud mode (below).

TWO MODES
  1) LOCAL (works now, nothing to set up): admin and shop share data only inside the SAME browser on the SAME device.
     Use it to try everything. Open the two files through a web server or hosting (not by double-clicking), e.g. run:  python -m http.server
     Admin PIN is the localPin value in admin.html (default 1234). This is only for trying; it is not real security.

  2) CLOUD (needed for a real shop): changes made on your phone/computer reach ALL customers. Free Firebase account:
     a. console.firebase.google.com -> Add project.
     b. Build -> Realtime Database -> Create database. Copy its URL (looks like https://NAME-default-rtdb.firebaseio.com).
     c. Build -> Authentication -> Get started -> Sign-in method -> Email/Password -> Enable. Then Users -> Add user: your email + a strong password. 
        (Settings -> User actions: turn OFF "create (sign-up)" if you see it.)
     d. Project settings -> General -> copy the "Web API key".
     e. Realtime Database -> Rules: paste the rules below (replace OWNER_EMAIL with your email) -> Publish.
     f. Fill firebaseUrl and apiKey in the setting block of BOTH index.html and admin.html. Then upload to hosting (Netlify, Cloudflare Pages, GitHub Pages).
     g. Open admin.html, sign in with that email + password.

  RULES (replace OWNER_EMAIL):
  {
    "rules": {
      "store":  { ".read": true, ".write": "auth != null && auth.token.email == 'OWNER_EMAIL'" },
      "photos": { ".read": true, ".write": "auth != null && auth.token.email == 'OWNER_EMAIL'" },
      "orders": {
        ".read": "auth != null && auth.token.email == 'OWNER_EMAIL'",
        ".write": "auth != null && auth.token.email == 'OWNER_EMAIL'",
        "$id": { ".write": "!data.exists()", ".validate": "newData.hasChildren(['total','items'])" }
      },
      "reviewsPending": {
        ".read": "auth != null && auth.token.email == 'OWNER_EMAIL'",
        ".write": "auth != null && auth.token.email == 'OWNER_EMAIL'",
        "$id": { ".write": "!data.exists()" }
      }
    }
  }
  Meaning: everyone can READ the shop data; only you can CHANGE it or read orders; customers can only CREATE new orders/reviews.

HOW TO PUBLISH (put the shop online)
  1. Finish CLOUD setup above first (otherwise customers will NOT see what you add or delete).
  2. Go to app.netlify.com/drop (free) and drag the kangaroo-shop folder (or kangaroo-shop.zip) onto the page. You get a web address.
  3. Customers open  https://YOUR-ADDRESS/            (index.html is the shop)
     You open       https://YOUR-ADDRESS/admin.html   (sign in with your Firebase email + password)
  4. In admin you can ADD products (one by one or many at once), DELETE products (one, or tick several), Restore deleted built-in products,
     change prices/stock/photos, offers and coupons. The header says "Published - live for everyone" after each change.
  Tip: keep the admin address private. Anyone can open the page, but only you can sign in and save.

REAL PHOTOS
  The site never shows fake photos. A product with no photo shows its emoji.
  Option A: in admin -> Products & photos, tap the camera button on a product: choose a photo from your device (it is shrunk automatically) or paste a photo link.
  Option B: put photo files in the images/ folder. Admin -> "Photo checklist (CSV)" lists the exact file name for every product.
  Use photos you took yourself or have the right to use.

NOT INCLUDED / LIMITS
  - Customer<->owner live chat is not part of this version (orders, price/stock, offers, coupons, settings, photos, reviews are).
  - Stock only shows "Sold out" at 0; it does not count down by itself.
  - Payments are still confirmed by you (Transaction ID check). There is no automatic payment verification.
  - The cloud mode was tested only against a simulated Firebase server here, not a real Firebase project. Test it with a few dummy orders first.
